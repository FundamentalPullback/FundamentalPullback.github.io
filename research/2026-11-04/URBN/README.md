# URBN conditional exploratory research
USD millions except prices, EPS, shares and percentages where labeled. This is not a calibrated WACC, certified owner FCF, current transaction bridge or entry authorization.

Offline reproduction, Python standard library:
1. `python history/build_history.py`
2. `python comparables/reproduce.py`
3. `python model.py`
4. `python report.py`
5. `python prepare.py`
6. `python qa.py`

Run `python package.py` afterward to rebuild manifest and ZIP. Public inputs contain extracted numeric facts, provenance, scripts and original analysis, not full issuer filings. Rental product amortization is not separately disclosed in extracted sources; do not add an invented amount to D&A or subtract gross rental purchases twice from CFO. The model retains operating rental costs and finances growth in net operating capital including rental product. Historical capital, trust assets, tax-credit liabilities, operating cash reserves and tax stress remain explicitly conditional. Prices disagree; the next earnings call is confirmed by issuer IR.
