# AEO reproducible partial research

Offline, standard Python only:
1. python history/build_history.py
2. python comparables/reproduce.py
3. python analyze.py
4. python report.py
5. python prepare.py
6. python qa.py

Optional python package.py creates archive and manifest. Numeric observations include primary filing URLs, inline-XBRL tags, contexts and periods. Full filings are excluded. History preserves direct/accumulated differences separately, not silently reconciled. 53-week FY2023 and NI parent/consolidated are distinct. Tariff refunds, incentives and participation-financing expense require separate treatment. All valuation/owner FCF/integral bridge fields remain null. Prior inventory write-down amount is from preliminary disclosure and used only as an illustrative sensitivity, not a certified normalization.
