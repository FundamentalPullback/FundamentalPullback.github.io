# AGCO reproducible partial observation
No integral valuation, owner FCF, equity bridge or entry permission.
Run offline using Python standard library:
1. python history/rebuild_history.py
2. python comparables/reproduce.py
3. python analysis.py
4. python prepare.py
5. python report.py
6. python qa.py
Then python package.py recreates the manifest and ZIP. History uses numeric SEC excerpts only. Reported accounting, limited impairment/disposal bridge and sustainable earnings are different concepts. Price discrepancies and unknown software investment remain explicit.
