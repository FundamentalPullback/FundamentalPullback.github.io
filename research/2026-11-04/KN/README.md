# KN reproducible conditional research

USD millions unless labeled otherwise. This is exploratory FCFF research, not a calibrated WACC, certified owner FCF, current transaction bridge or entry authorization.

Offline Python standard-library reproduction from this directory:
1. `python history/rebuild_history.py`
2. `python comparables/reproduce.py`
3. `python model.py`
4. `python report.py`
5. `python prepare.py`
6. `python qa.py`

The public packet contains numeric inputs, source references, original analytical prose and executable scripts, not complete issuer filings. Market references disagree and do not constitute a single certified close. All scenarios use the same explicit and terminal reinvestment floors. Sensitivities are assumptions, not company guidance. The bridge excludes Syntiant assets unless included in a separately labeled carrying-value sensitivity and does not add pension deficit twice to deferred compensation. Full source documents used for research remain outside the public packet. `package.py` rebuilds the manifest and ZIP after the six analysis steps.
