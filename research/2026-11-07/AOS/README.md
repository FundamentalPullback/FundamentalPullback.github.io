# AOS conditional research package

Report date: 7 November 2026. Currency: USD. This package contains authored research and calculations, not original company filings.

Read report.html or report.md first. Valuation scenarios are exploratory and conditional. Stage 3 is not complete; there is no approved valuation, entry, margin of safety or review threshold.

To reproduce with standard Python, from this folder run:

    python model.py
    python build_report.py

The commands reproduce model.json, qa.json, sources.json, summary.json, report.md and report.html. No network or third-party Python package is required. Sources identify public URLs, titles, dates and purpose only.

Summary evidence strings are authored report text. sourceUrl/sourceUrls identify underlying public inputs, not verbatim company quotations. Derived valuation claims are explicitly labeled as analyst calculations; report.html is the evidence artifact.

Visual layout has not been independently certified. The report explains transaction, tariff, accounting-perimeter and comparable-history limitations.
