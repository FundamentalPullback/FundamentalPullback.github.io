# PRCH factual research package
As of 7 November 2026. This is a partial financial and capital review, not a valuation approval or trade recommendation.

Read report.md first. summary_es.md and summary_en.md provide short summaries. inputs.json contains derived source inputs; normalized_financials.csv is generated by reproduce.py. source_ledger.csv contains public source URLs, titles, dates and purposes only. evidence_cards.json contains exact contiguous excerpts of report.md mapped to public sources.

Run `python reproduce.py` from any working directory. The script needs only the Python standard library and reads the adjacent inputs.json. It overwrites normalized_financials.csv and validation.json in this folder.

Validation has eight passing checks and two intentionally false checks. The two false checks preserve differences between the quarterly earnings release and cumulative filing subtraction for CFO ($0.162 million) and cash capex ($0.161 million). They are unresolved financial-data exceptions, not script execution failures. No guessed correction is applied. qa_flags.csv describes these and other limitations.

The $57.920 million loss and loss adjustment expense reserve is the reported balance-sheet liability before separately presented reinsurance recoverables, not the net reserve triangle measure. The shareholder-perimeter CFO TTM figure of $78.643 million is calculated from annual and nine-month consolidated CFO less reciprocal CFO; a check ties it to the report.

The package contains authored analysis and reproducible derived inputs only, without reproducing original filing documents. No target price, entry approval, trade, or remote publication is made. Manifest entries describe only these public artifacts; the ZIP is a portable copy of this folder.
