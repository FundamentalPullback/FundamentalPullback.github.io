# Dover research package

Start with report.md. This is conservative conditional research, not a certified current fair value or approved trade. Stage 3 remains incomplete. The September capital bridge does not claim to represent settled November financing balances.

Run `python model.py` in this directory to regenerate inputs.json, results.json, actuals.csv and qa.json. Python standard library only. The model discounts ten full forward years with no calendar stub. All forecast assumptions and exclusions appear in the report.

summary.json provides English and Spanish decision text and explicit approval flags. evidence.md provides short contiguous primary-source excerpts. sources.json contains only public URLs, titles, dates and research purposes. manifest.json lists the approved public package contents. No full source filings are redistributed.
